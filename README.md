# Facebook Video Downloader

### Python utility powered by yt-dlp

A small command-line script for downloading supported videos from accessible URLs using yt-dlp.

## Requirements

- Python 3
- pip
- yt-dlp

## Install

```bash
git clone https://github.com/Gh0stDeveloper/Facebook-download.git
cd Facebook-download
python -m pip install yt-dlp
```

## Run

```bash
python facebook_video_downloader.py
```

Enter a supported video URL when prompted.

## Usage notice

Only download media when you have permission and doing so complies with the source platform's terms and applicable law. External site and library changes can affect compatibility.
